# CreatorPilot static UI prototype

This directory contains a desktop-first, English-language static HTML prototype for the CreatorPilot MVP. It uses no framework or external assets.

Open `index.html` to enter the product prototype, or `login.html` to start from authentication. The pages share `styles.css` and `app.js` and are linked into the principal user flows described in `docs/creatorpilot-mvp-user-creation-flow-discussion.md`.

## Screens

1. `login.html` — authentication
2. `onboarding.html` — first channel setup
3. `index.html` — chat-first home
4. `events.html` — all news events
5. `event-detail.html` — event evidence and timeline
6. `chat.html` — AI-assisted topic development
7. `direct-create.html` — direct creation input
8. `direction.html` — content direction confirmation
9. `output-select.html` — output and production specifications
10. `x-delivery.html` — X Post delivery
11. `video-delivery.html` — short-form video package
12. `history.html` — creation history
13. `project.html` — persistent project workspace
14. `channels.html` — channel management
15. `settings.html` — account and product settings

All data, notifications, credits, generation states, and actions are representative prototype content rather than connected product behavior.
