OpenAI expands ChatGPT agent capabilities for multi-step web tasks

OpenAI announced new controls for longer-running agent tasks. Users can review proposed actions, monitor progress and intervene before sensitive steps. The feature is rolling out gradually, and exact availability varies by plan and region.

What happened

AI summary
  • Users can inspect the agent's plan before it starts a longer web task.
  • Sensitive actions require explicit confirmation rather than silent execution.
  • A live activity view exposes progress, errors and waiting states.
  • Rollout timing and plan-level limits are not yet consistent across all regions.
Uncertainty to keep visible

Availability by plan and region is still inconsistent. Avoid stating that every ChatGPT user has access today.
